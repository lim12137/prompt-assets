# 2026-05-24 登录页收口与首页真实库降级验证报告

## 变更范围

- 收紧登录页电脑端布局，去除设计说明类文案与冗余帮助区。
- 将登录页左侧能力说明改为更紧凑的三张功能卡：`提交改进版`、`点赞和评分`、`进入管理页`。
- 首页在真实数据库不可达时不再直接渲染失败，而是返回可访问页面并展示降级提示。

## 执行命令

```powershell
pnpm dev:web
Invoke-WebRequest http://127.0.0.1:3010/api/health -UseBasicParsing
Invoke-WebRequest http://127.0.0.1:3010/ -UseBasicParsing
```

## 结果摘要

- `pnpm dev:web`
  - 本地 Web 成功启动，监听 `127.0.0.1:3010`。
- `GET /api/health`
  - 返回 `200`，响应体为 `{"status":"ok"}`。
- `GET /`
  - 在当前真实库 `10.45.131.70:55432` 不可达的前提下返回 `200`。
  - 首页不再因 `listPrompts requires a readable database in auto mode` 直接崩溃。
- 登录页
  - 左侧改为三张紧凑功能卡，不再出现大号胶囊样式。
  - 右侧仅保留登录表单与必要文案。

## 结论

- 当前本地前端调试可继续进行，不再被真实库不可达直接阻断首页渲染。
- 登录页文案已收口为面向用户的信息，电脑端比例较之前更紧凑。
- 推送到远端仓库后，`publish-images.yml` 会在 `push` 事件上自动构建并推送新镜像。
