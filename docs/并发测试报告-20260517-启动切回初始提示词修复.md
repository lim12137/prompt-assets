# 并发测试报告-20260517-启动切回初始提示词修复

## 变更目标
- 覆盖 `buildExecutionPlan("dev")` 不再包含 `db-seed`。
- 覆盖 `auto` 模式下数据库不可读时，不再静默回退 fixture。

## 本次测试命令
```bash
node --test tests/unit/scripts/local-debug.test.mjs
node --test --experimental-strip-types tests/unit/api/prompt-repository-auto-no-fixture-fallback.test.ts
```

## 结果摘要
- `tests/unit/scripts/local-debug.test.mjs`
  - 结果：通过
  - 汇总：`tests 15, pass 14, fail 0, skipped 1`
  - 关键点：`buildExecutionPlan("dev")` 断言为 `["db-up","db-migrate","web"]`，并显式断言不包含 `db-seed`。
  - 备注：存在 1 条与环境端口占用相关的既有跳过（`port 3010 already occupied by external process`），与本次改动无关。
- `tests/unit/api/prompt-repository-auto-no-fixture-fallback.test.ts`
  - 结果：通过
  - 汇总：`tests 1, pass 1, fail 0`
  - 关键点：在 `PROMPT_REPOSITORY_DATA_SOURCE=auto`（未显式设置 `fixture`）且 `DATABASE_URL` 不可达时，`listPrompts()` 抛出包含
    `requires a readable database in auto mode` 与 `Refusing to fallback to fixture prompts`
    的错误，证明不再静默回退 fixture。
