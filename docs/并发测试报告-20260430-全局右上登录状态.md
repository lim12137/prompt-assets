# 并发测试报告-20260430-全局右上登录状态

## 变更目标
- 实现全站右上角常驻登录状态：
  - 未登录显示“登录”
  - 已登录显示用户标识和“退出”
  - 登录链接尽量保留当前路径 redirect

## 测试命令与结果

1. 单元测试（登录链接与 admin 重定向）

```bash
node --test --experimental-strip-types tests/unit/auth/login-link.test.ts tests/unit/auth/admin-redirect.test.ts
```

- 结果：`5 passed, 0 failed`

2. E2E 冒烟（全局右上登录状态）

```bash
pnpm exec playwright test tests/e2e/smoke/global-auth-header.spec.ts
```

- 结果：`2 passed, 0 failed`

3. 运行中服务页面验证（3013）

```powershell
Invoke-WebRequest -Uri http://127.0.0.1:3013/prompts/js-code-reviewer -UseBasicParsing
Invoke-WebRequest -Uri http://127.0.0.1:3013/ -Headers @{Cookie="auth_token=<generated-token>"} -UseBasicParsing
```

- 结果摘要：
  - 未登录详情页 HTML 包含 `/login?redirect=%2Fprompts%2Fjs-code-reviewer`，且包含“登录”
  - 已登录首页 HTML 包含“验证用户”与“退出”

## 结论
- 右上登录状态在未登录/已登录场景均符合预期。
- redirect 保留当前路径已生效（至少在 `/prompts/[slug]` 场景和 e2e 覆盖路径中成立）。
