# 真实库样例清理执行说明

## 目标

用独立脚本对真实库中的样例提示词做两段式清理：

1. `--dry-run` 只预览待删对象摘要
2. `--confirm` 在人工确认后真正删除

脚本文件：`scripts/cleanup-real-db-sample-prompts.mjs`

## 输入约束

- 只能接收明确的 `slug` 清单
- 不支持关键字、分类、状态等模糊条件删库
- `slug` 可通过两种方式提供：
  - 重复传入 `--slug`
  - 通过 `--input` 读取 JSON 文件

支持的 `--input` 文件格式：

```json
["sample-alpha", "sample-beta"]
```

或：

```json
{
  "slugs": ["sample-alpha", "sample-beta"]
}
```

## 运行前提

- 已安装仓库依赖
- 环境变量已指向目标真实库
- 若真实库处于较早 schema 版本，缺少 `prompt_version_likes` 表时，脚本会自动按 `0` 处理版本点赞计数，不阻断 `dry-run`
- 优先使用 `DATABASE_URL`
- 若未设置 `DATABASE_URL`，脚本会回退读取：
  - `POSTGRES_HOST`
  - `POSTGRES_PORT`
  - `POSTGRES_DB`
  - `POSTGRES_USER`
  - `POSTGRES_PASSWORD`

## 命令

### 1. 预览待删对象

```powershell
node scripts/cleanup-real-db-sample-prompts.mjs --dry-run --slug sample-alpha --slug sample-beta
```

或：

```powershell
node scripts/cleanup-real-db-sample-prompts.mjs --dry-run --input .tmp/real-db-sample-prompts.json
```

输出为 JSON 摘要，包含：

- `requestedSlugs`
- `missingSlugs`
- `prompts`
- `summary`
- `ready`

只有 `ready: true` 时，才允许进入确认删除。

### 2. 确认执行删除

```powershell
node scripts/cleanup-real-db-sample-prompts.mjs --confirm --input .tmp/real-db-sample-prompts.json --operator admin@example.com --reason "首批样例清理"
```

`--confirm` 必填参数：

- `--operator`：执行人标识
- `--reason`：删除原因

输出为 JSON 结果，包含：

- `executedAt`
- `operator`
- `reason`
- `deletedSlugs`
- `prompts`
- `summary`

## 删除范围

脚本按提示词 `slug` 定位目标后，会在事务内删除目标提示词，并允许级联清理关联历史，包括：

- `prompt_versions`
- `submissions`
- `prompt_likes`
- `prompt_version_likes`
- `prompt_version_scores`
- `prompt_version_daily_interactions`
- `prompt_categories`

说明：

- 删除前会先删除 `submissions`
- 删除前会先把 `prompts.current_version_id` 置空
- `audit_logs` 不做级联物理清理，脚本会新增一条批量清理审计记录

## 注意事项

- 先跑 `--dry-run`，确认摘要与 `missingSlugs` 无误后再执行 `--confirm`
- 若 `missingSlugs` 非空，脚本不会执行确认删除
- 不要把测试库、fixture、seed 文件当作这次清理入口；本脚本只面向真实库
