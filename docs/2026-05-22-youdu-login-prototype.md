# 有度一体化平台账号登录原型说明

文件：`docs/2026-05-22-youdu-login-prototype.html`

## 目标

- 基于当前项目 `/login` 的朴素单列表单，补足企业内部门户风格的品牌区、登录说明区、帮助区。
- 仅产出高保真原型，不修改 `apps/web` 下业务代码。
- 明确体现“有度一体化平台账号登录”“账号密码登录”“登录说明/帮助区”。

## 设计要点

- 双栏布局：
  - 左侧为企业门户品牌与登录背景信息。
  - 右侧为登录主卡片和帮助说明。
- 视觉方向：
  - 延续企业系统稳重气质，主色偏蓝灰，登录按钮与重点提示用红色强调。
  - 使用玻璃感卡片、分层边框和轻背景纹理，明显优于原始表单，但不过度互联网化。
- 响应式：
  - 桌面端双栏。
  - 移动端自动堆叠为单栏，保留表单优先级和帮助信息可读性。

## 与当前登录页的差异

- 当前页只有标题、两个输入框、按钮和状态文案，缺少场景说明与品牌识别。
- 新原型增加：
  - “有度一体化平台账号登录”主标题
  - “账号密码登录”方式标签
  - 登录说明 / 常见问题 / 安全建议 / 帮助入口
  - 更完整的企业门户视觉层次

## 落地边界

- 本次只是 `docs/` 下独立 HTML 原型。
- 未接入真实接口、未改 React/Next 页面、未新增业务逻辑。
